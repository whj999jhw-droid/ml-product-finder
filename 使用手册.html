ML Product Finder 使用手册

美客多爆款采集 → 货源利润测算 → 合规上架　·　更新于 2026-07-31

三步上手：① 双击桌面 MLProductFinder-Launcher.bat → ② 浏览器打开 http://localhost:5173 → ③ 左侧点「美客多商品抓取」，直接点绿色抓取按钮。

一、启动

  1. 双击桌面启动器
    C:\Users\whj87\Desktop\MLProductFinder-Launcher.bat
    它会先清理 5173 / 3000 端口，再同时拉起后端（3000）和前端（5173）。不会自动开浏览器。
  2. 手动打开浏览器，访问 http://localhost:5173
  3. 看到左侧出现「美客多商品抓取 / 货源与利润 / 合规上架」三个入口，即启动成功。

命令行启动（备用）

cd c:\Users\whj87\WorkBuddy\20260720124310\ml-product-finder
npx tsx server/index.ts    # 后端 :3000
npx vite                   # 前端 :5173（另开一个终端）

二、M1 · 抓爆款

  1. 进入「美客多商品抓取」页
  2. 勾选站点：墨西哥 MLM / 巴西 MLB / 智利 MLC / 哥伦比亚 MCO。
    新手建议先只勾 墨西哥 单站点试跑，快很多。
  3. 设置价格上限（默认 $15）与筛选开关：
    开关作用建议
    排除 ML Full剔除平台仓发货的竞品✅ 开（你是自发货）
    仅跨境（排除本土）剔除当地卖家✅ 开
    仅全新剔除二手✅ 开
    展开子分类扩量数据翻几倍但极慢❌ 先关
  4. 点「开始抓取」，页面会实时显示进度条与当前分类。
    全量 54 个分类约需 20+ 分钟。未配住宅代理时每个分类最多约 20 条（官方接口上限）；配了住宅代理可翻页放量到几百条/类。
  5. 抓完自动导出 xlsx 到 data\exports\，文件名形如 ML_Products_2026-07-31.xlsx。若开了邮件推送，会自动作为附件发到你邮箱。

三、M2 · 找货源 + 算利润

左侧点「货源与利润」，页面会自动读取 M1 最新导出的爆款清单。

① 填货源价

  1. 手工模式（推荐，稳定）：拿商品标题/图片去 1688 搜同款，把采购价填进「货源价CNY」列，链接粘到「货源链接」列。头程运费不填则系统按计费重自动估算。
  2. 自动图搜：点行尾「自动图搜」按钮。需先配环境变量 ML_1688_APPKEY / ML_1688_SECRET / ML_1688_TOKEN，没配会提示降级为手工模式。

② 两种测算，用哪个？

表格里的「净利润 / ROI」列

输入货源价就实时刷新的快速估算，只算佣金+回款费，适合边填边扫一眼。

「完整测算」按钮 重要

调用后端完整引擎，才是真实到手利润。点一次全表刷新。

完整测算把这些全算进去：

成本项说明
平台佣金MLM 4% / MLB 12.5% / MLC·MCO 12%
Mercado Pago 手续费4%~4.5%
官方物流费按体积重（长×宽×高÷5000）与实重取大计费
头程运费手填优先，未填按计费重 ×30~40 元/kg 估算
关税 / 进口税墨西哥无 RFC 税号扣 36%，有 RFC 才 11.5%；巴西 ICMS 20%；智利/哥伦比亚 0
广告费按 ACoS 默认 5%
退款损耗退货率 × 40% 损失
汇率损耗 + 提现手续费约 1% + 1%

③ 看结果

绿 净利率 ≥ 20%，可放心做
黄 净利率 5%~20%，需压成本或提价
红 净利率 < 5%，别碰

保本价列：低于这个价卖必亏，会标红。
鼠标悬停在净利率上可看风险预警，例如「体积重是实重的 6.2 倍，泡货运费失控，建议放弃」。

四、M3 · 合规上架

⚠️ 合规红线（必须遵守）：
① 标题必须自己重写，不能复制竞品标题；② 图片必须是你自拍或供应商授权的图，严禁盗用竞品原图；③ 品牌栏填 Generic 或你自己的品牌，绝不填 Nike/Apple 等他人品牌。
违反 = 封店 + 侵权索赔。工具的预检会拦，但最终责任在你。
  1. 先授权店铺：在「美客多商品抓取」页点「授权我的店铺」，走 OAuth 拿到含 write 权限的 token（上架必须）。
  2. 左侧点「合规上架」，从下拉里选一条 M2 筛出来的商品作为参考。
  3. 逐项填写你自己的内容：
    字段怎么填
    站点 / 类目ID类目ID 从 M2 清单里带过来，可直接用
    标题自己写，西语站用西语、巴西用葡语，突出材质+用途+规格
    售价参考 M2 的保本价，往上加 20%+ 利润
    库存 / 品牌库存按备货填；品牌填 Generic
    图片 URL你自有图的公网地址（图床/OSS），多张用换行分隔
    重量 / 长宽高如实填，直接影响运费与体积重
  4. 点「合规预检」。会扫描品牌侵权词（75 个大牌）+ 西语/葡语平台违禁词（replica、cura、milagroso 等）。
    预检不过就改，改到显示「合规预检通过」。
  5. 点「立即上架」，成功后返回 itemId 和商品链接。
批量上架后端已就绪（并发 3、429 自动指数退避重试、逐条预检拦截、单批≤50 条），接口 POST /api/ml/listing/publish-batch，前端按钮还没接。需要的话可以让我补上。

五、自动化：邮件推送 + 定时抓取

邮件推送

在「美客多商品抓取」页找到「邮件通知」卡片：

  1. 展开「发件人 SMTP 设置」，填主机/端口/账号/授权码（QQ 邮箱用授权码不是登录密码）
  2. 填收件邮箱，打开开关，点「保存」
  3. 点「发送测试邮件」确认能收到

之后每次抓取完成，xlsx 会自动作为附件发给你。

定时自动抓取

在「定时自动抓取」卡片设一个时间（如 08:00）并开启，程序开着的话每天到点自动跑一遍上次的站点与筛选条件。

定时依赖程序常驻运行。关机或关掉启动器窗口就不会执行。

六、进阶：住宅代理放量

不配代理时官方接口每类目只给约 20 条。想要几百条/类，需要地理匹配的住宅代理（MX/BR/CL/CO 出口 IP）：

  1. 在「住宅代理（可选）」卡片填入代理地址，如 http://用户名:密码@mx.decodo.com:20000
  2. 点「保存」→ 点「测试」，通了就会自动解锁 search 接口翻页（最多 40 页 × 50 条/类）
数据中心代理（Cloudflare Worker / Render / 普通 VPS）无效，会被平台风控挡掉，必须是住宅 IP。

七、常见问题

现象处理
页面打不开 / 白屏确认启动器窗口没关；重新双击 bat（会自动清端口）
抓取一直 0 条token 过期。程序每 30 分钟自动续期，实在不行重启一次启动器
「货源与利润」页没数据先跑一次 M1；或点「刷新数据」重读最新导出
完整测算全是红灯大概率是墨西哥站没 RFC 被扣 36%。要么注册 RFC，要么改做智利/哥伦比亚（0 进口税）
上架报 401 / 无 write 权限重新走一遍「授权我的店铺」，确认 scope 含 write
自动图搜提示不可用没配 1688 密钥，用手工粘贴模式即可，不影响使用

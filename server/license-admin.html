使用说明（点击展开，第一次用请看）

这个页面用来管理 App 的激活码：看所有码、生成新码、解绑、吊销。

  1. 登录：在下面填入「管理员码」，点登录。管理员码可以在任意多台设备上激活，不会被"一码一设备"限制。
  2. 生成：填数量（1–500）和类型，点「生成新码」。生成的码会出现在下方列表，点码即可复制。
  3. 解绑：客户换了手机、或者码被占住了，点「解绑」，这个码就恢复成未使用，可以在新设备上重新激活。码本身还在。
  4. 吊销：不想让这个码再用了，点「吊销」。吊销是不可用的，再想用只能重新生成。
  5. 状态：未使用＝还没人激活；已激活＝已绑定某台设备；已吊销＝作废。

普通用户码是"一码一设备"：一个码只能绑一台设备，换设备要先解绑。
